# Portfolio app

The Next.js app behind [jayrb.dev](https://jayrb.dev) — see the [root README](../README.md) for the full overview, tech stack, and project structure.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). The page content and project data live in [`app/page.tsx`](app/page.tsx).

## Build & lint

```bash
npm run build   # production build
npm run start   # serve the production build
npm run lint    # ESLint
```
